# 🏦 Loan Approval Prediction

A Machine Learning project that predicts loan approval status using a Decision Tree classifier.

## Features
- Loads loan applicant data using Pandas.
- Converts text into numerical features.
- Trains a Decision Tree model.
- Evaluates model performance.
- Saves the trained model and vectorizer.
- Provides a Streamlit web application for predictions.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- SciPy
- Streamlit

## Model Accuracy
The model achieved approximately **92.14% accuracy** in my test run. Results may vary, and predictions are not guarantees of actual bank decisions.

## How to Run

Install the required libraries:

```bash
pip install pandas scikit-learn scipy streamlit
```

Run the web application:

```bash
python -m streamlit run loan1.py
```

## Disclaimer
This project is for educational purposes. Predictions should not be used as the sole basis for real financial decisions.
